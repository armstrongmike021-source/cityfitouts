# cityfitouts.com.au

City Fitouts - Mike's public commercial-fitout brand (owned by Estier Pty Ltd, but Estier is NOT named on the
site, Mike 2 Nov 2026). A BUILDER only: no design services offered or mentioned anywhere. Replaces Republic
Design Build after the split with Trevor (2 Nov 2026). Static site, no build step beyond the generator. Netlify
deploys from this repo (branch main, publish "."), so a push to main is a deploy, same as Block Checker.

- EVERY page is GENERATED by `tools/build.py` - home, /our-projects, /commercial-fitouts-sydney, /fitout-cost,
  /about, /contact, thanks.html, city.css, plus the five SEO space pages (`SPACES`: /office-fitouts-sydney,
  /retail-fitouts-sydney, /cafe-restaurant-fitouts-sydney, /medical-fitouts-sydney, /childcare-fitouts-sydney).
  It also writes `_redirects`, `sitemap.xml` and `robots.txt`. Edit copy in build.py, run `python3 tools/build.py`.
  Never edit the .html. The build asserts no page contains "design &", "design and construct", "Republic" or "Trevor".
- `style.css` is the Sydney Fitouts stylesheet; `city.css` overrides it (navy only, no amber accent, steps, projects,
  footer columns). Jost for all text.
- Calculator (`CALC` / `CALC_JS` in build.py): same RATES/WEEKS as sydneyfitouts.com, all-in design-and-construct,
  shown as Construction / Design (your architect or designer) / Approvals. Mike put the design row BACK (2 Nov 2026)
  because the design fee may go to the architect who referred the job. The section id is `checker`, NOT `cost` -
  `$('cost')` is the price element and an id clash hid the whole calculator once.

  Projects: KFC Garbutt, Macpac Warringah Mall, Kareela Community Pharmacy (real jobs, photos saved from the old
  Republic site). Mecca is OFF the site (pink, Mike 2 Nov 2026). The rest are Grok renders from
  Dropbox/Marketing/Sydney Fitouts - never captioned as real work.
- Leads: Netlify Forms (`fitout-quote`) -> `netlify/functions/submission-created.js` -> the same Apps Script relay as
  Sydney Fitouts (env LEAD_URL / LEAD_SECRET, copy from the Sydney Fitouts Netlify project), source cityfitouts.com.au.
- sydneyfitouts.com is the private SEO feeder: its footer and quote lines point here (branch `city-fitouts-handover`
  in the sydneyfitouts repo, 2 Nov 2026). Its pages are COST pages; these are BUILDER pages - keep the copy different
  so the two sites do not cannibalise each other.
